# NMAMIT IIC Report Portal

A Vercel-ready Next.js application for IIC Coordinators at NMAM Institute of Technology, Nitte.

## Run locally
1. Install Node.js 20+.
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`

## Deploy to Vercel
Push this folder to GitHub, import the repository in Vercel, and deploy. Vercel supports zero-configuration Next.js deployments.

## Current prototype
- Coordinator login UI
- Dashboard
- Create/Edit report
- NMAMIT IIC fields
- Live preview
- Save drafts in browser session
- Four-page A4 PDF generation
- Ready for adding persistent database/authentication and actual logos/photos

Demo login accepts any username/password.
